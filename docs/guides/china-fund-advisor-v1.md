# China Fund Advisor V1 使用说明

## 定位

这是一个面向中国境内公募基金的“证据型研究助手”。它不会自动交易，也不会承诺收益。V1 将工作拆成两层：

1. Python 从公开数据中读取基金身份、单位净值和定期披露持仓，并计算历史指标。
2. DeepSeek 只负责用中文解释已经计算好的证据，不负责计算数字，也不能给出直接交易指令。

这种设计的原因是：大模型擅长解释，但不应作为净值、回撤、波动率等金融数值的唯一计算器。

## 当前覆盖

- 6 位中国公募基金代码校验。
- 基金名称、类型、管理人、基金经理、成立日期、规模和业绩比较基准。
- 开放式基金单位净值和累计净值历史；收益与回撤优先按公布的每日增长率复利重建，减少分红和份额折算造成的口径失真。
- 最新可取得的股票、债券持仓和行业配置。
- 区间收益、年化收益、年化波动率、最大回撤、历史一日 VaR(95%)、上涨日比例。
- 在显式提供无风险利率假设时计算夏普比率。
- DeepSeek 的证据约束型中文报告。
- 每个数据集的来源、数据日期、抓取时间和数据缺口。

V1 不覆盖货币基金的万份收益/七日年化、场内 ETF 盘中价格、基金申赎确认、税费测算、个人组合适配性和自动交易。

## 数据边界

- 净值不是盘中价格。开放式基金净值通常在交易日收盘后更新。
- 持仓来自季报、半年报或年报，不能视为基金当前实时持仓。
- AKShare 是数据接口库，底层公开页面可能调整；重要决定应回到基金管理人官网、基金合同、招募说明书和产品资料概要核对。
- 历史指标描述过去，不预测未来。极端损失可能超过历史样本。

## 配置 DeepSeek

复制 `.env.example` 为 `.env`，只在本机填写：

```dotenv
DEEPSEEK_API_KEY=你的密钥
DEEPSEEK_BASE_URL=https://api.deepseek.com
```

不要把 `.env`、API Key、账户截图或持仓账户明细提交到 Git。

夏普比率需要一个明确的年化无风险利率假设。若你确实需要该指标，可以在 `.env` 中设置小数形式：

```dotenv
FUND_ANNUAL_RISK_FREE_RATE=0.015
```

`0.015` 表示 1.5%。不设置时系统会主动省略夏普比率，避免暗藏未经确认的宏观假设。

## 运行

先安装项目依赖，然后在仓库根目录执行：

```powershell
python -m tradingagents.funds.cli 000001 --output reports/fund-000001.md
```

仅验证数据和数学指标，不调用 DeepSeek：

```powershell
python -m tradingagents.funds.cli 000001 --no-ai
```

回测到某个历史截止日：

```powershell
python -m tradingagents.funds.cli 000001 --as-of 2025-12-31 --no-ai
```

`--as-of` 只会截断净值；公开接口返回的历史持仓可能不完整，因此报告仍会显示持仓披露期，不能把它当成严格的无前视偏差回测。

## 小白怎么看报告

- 区间收益：起止两日单位净值的变化，不等于你的账户真实收益，申购日期、费用和分红方式都会影响结果。
- 年化收益：把较长历史折算为一年，仅用于理解历史速度；少于 180 天时系统不展示。
- 年化波动率：历史日收益的起伏程度，越大通常意味着体验越颠簸，但不能单独判断好坏。
- 最大回撤：历史上从一个高点跌到随后低点的最大幅度。它是过去发生过的损失，不是未来损失上限。
- VaR(95%)：历史样本中约 5% 的交易日损失会超过该值；极端情况下可能远超。
- 夏普比率：超出无风险利率的历史收益与波动之比；它对所选时间窗口和无风险利率很敏感。

## 在任何个性化讨论前需要回答

1. 这笔钱的用途和最晚用钱时间。
2. 是否已有 6–12 个月应急金，以及是否存在高息负债。
3. 账户下跌多少会影响睡眠或迫使你卖出。
4. 现有现金、存款、债券、基金、股票和房产的大致比例。
5. 单只基金计划占可投资资产的比例。
6. 是否能接受封闭期、QDII 汇率风险、行业集中或信用风险。

在这些信息缺失时，系统只做产品研究，不判断“适不适合你”。

## 设计依据

- [证券期货投资者适当性管理办法](https://www.csrc.gov.cn/csrc/c101939/c1045348/content.shtml)：产品或服务需要结合投资者风险承受能力进行适当性匹配，因此在用户目标、期限和亏损承受能力缺失时，V1 不输出个性化适配结论。
- [证券投资基金评价业务管理暂行办法](https://www.csrc.gov.cn/csrc/c106256/c1653866/content.shtml)：基金评价强调长期、公正和全面，不应混合不同类别，不应把单一指标作为唯一标准，评价结果也不应被视作未来预测或投资建议。
- [公开募集证券投资基金销售机构监督管理办法](https://www.csrc.gov.cn/csrc/c106256/c1653806/content.shtml)：禁止预测基金投资业绩或宣传预期收益率，并要求显著揭示风险。本项目不是销售机构，但采用更保守的同类输出边界。
- [公开募集证券投资基金业绩比较基准指引](https://www.csrc.gov.cn/csrc/c100028/c7610827/content.shtml)：业绩比较基准应与产品投资风格相匹配。V1 在缺少基准收益数据时不会自行选择替代基准。
- [AKShare 公募基金接口文档](https://akshare.akfamily.xyz/data/fund/fund_public.html)：V1 使用文档化的基金基本信息、净值、持仓和行业配置接口，并在报告中保留接口名和数据日期。

这些规则用于产品安全设计，不代表本项目已取得基金销售、基金评价或基金投资顾问业务资格。

## 版本路线

- V1：公开数据、确定性历史风险指标、来源记录和 DeepSeek 证据解释。
- V2：历史相似情景概率、样本外基线门控、多 Agent 辩论、证据审查和裁决。
- V3：个人组合穿透、相关性、行业重叠、目标期限和亏损承受能力。
- V4：按真实样本外成绩校准 Agent 权重、市场状态识别、模型漂移监控和预测复盘。

所有版本均不自动下单、不连接证券账户、不承诺收益。
